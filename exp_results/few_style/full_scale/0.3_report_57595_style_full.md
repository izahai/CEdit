# Few-style erasure evaluation

The aggregate values are from the server's `summary.csv`; the matching
per-content results and run fingerprints are preserved in `detailed_metrics.csv`.

> The full workflow completed on `root@180.189.55.43`, SSH port `57595`.
> SPEED uses threshold `0.1`, `aug_num=10`, and anchor `art`. Ours uses TGPRS
> threshold `0.3`, `retain_scale=0.5`, `aug_num=0`, anchor `art`, and 30
> artist-neutral subspace anchors (configured and applied rank 30). Sampling uses
> seed 0, DPM-Solver, 20 denoising steps, and CFG 7.5. Each artist metric uses
> 300 images and each MS-COCO metric uses 1,000 images. The completed run contains
> 17,500 PNG files and six edited checkpoints.

Lower target CLIP score indicates stronger erasure. Lower non-target and MS-COCO
FID and higher MS-COCO CLIP score indicate better preservation. Bold values are
the better edited-model result within each task.

## Result summary

TGPRS reduces target CLIP score relative to the unedited model for all three
artists, but SPEED produces the lower target score in every task: by 0.22 for
Van Gogh, 0.73 for Picasso, and 0.35 for Monet. TGPRS improves mean non-target
FID over SPEED only for Picasso (25.03 versus 25.44); it is worse by 6.31 for Van
Gogh and 1.49 for Monet. TGPRS has slightly higher MS-COCO CLIP score in all three
tasks, while its MS-COCO FID is worse by 1.09–1.93 points.
