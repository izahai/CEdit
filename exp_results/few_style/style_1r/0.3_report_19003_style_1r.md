# Few-style erasure evaluation with rank-1 style subspace

The aggregate values are from the server's `summary.csv`; the matching
per-content results and run fingerprints are preserved in `detailed_metrics.csv`.

> The workflow completed on `root@61.32.91.194`, SSH port `19003`.
> SPEED uses threshold `0.1`, `aug_num=10`, and anchor `art`. Ours uses TGPRS
> with the original target prompts (`erase_style=false`), threshold `0.3`,
> `retain_scale=1.0`, `aug_num=0`, anchor `art`, and one subspace anchor (`art`),
> with configured and applied residual rank 1. Sampling uses seed 0, DPM-Solver,
> 20 denoising steps, and CFG 7.5. Each artist metric uses 30 images and each
> MS-COCO metric uses 100 images. The run contains 1,750 PNG files and six
> edited checkpoints.

Lower target CLIP score indicates stronger erasure. Lower non-target and MS-COCO
FID and higher MS-COCO CLIP score indicate better preservation. Bold values are
the better edited-model result within each task.

## Result summary

Rank-1 TGPRS reduces target CLIP score relative to the unedited model for all
three artists: by 3.13 for Van Gogh, 2.09 for Picasso, and 3.81 for Monet.
SPEED produces the lower target score in every task, by 0.30 for Van Gogh, 0.23
for Picasso, and 0.76 for Monet.

TGPRS has worse mean non-target FID than SPEED by 14.40 for Van Gogh and 1.76
for Picasso, while it improves Monet by 0.01. Its MS-COCO CLIP score is lower
than SPEED by 0.157 for Van Gogh, but higher by 0.131 for Picasso and 0.141 for
Monet. TGPRS improves MS-COCO FID over SPEED by 1.59 for Van Gogh and 0.54 for
Monet, while it is worse by 0.52 for Picasso.
