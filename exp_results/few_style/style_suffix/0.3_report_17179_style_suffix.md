# Few-style erasure evaluation with style-suffixed targets

The aggregate values are from the server's `summary.csv`; the matching
per-content results and run fingerprints are preserved in `detailed_metrics.csv`.

> The workflow completed on `root@61.32.91.194`, SSH port `17179`.
> SPEED uses threshold `0.1`, `aug_num=10`, and anchor `art`. Ours uses TGPRS
> with target embeddings computed from prompts suffixed by `style`, threshold
> `0.3`, `retain_scale=1.0`, `aug_num=0`, anchor `art`, and 30 artist-neutral
> style anchors (configured and applied rank 30). Sampling uses seed 0,
> DPM-Solver, 20 denoising steps, and CFG 7.5. Each artist metric uses 30 images
> and each MS-COCO metric uses 100 images. The run contains 1,750 PNG files and
> six edited checkpoints.

Lower target CLIP score indicates stronger erasure. Lower non-target and MS-COCO
FID and higher MS-COCO CLIP score indicate better preservation. Bold values are
the better edited-model result within each task.

## Result summary

With style-suffixed target embeddings, TGPRS reduces target CLIP score relative
to the unedited model for Picasso and Monet by 1.52 and 1.55 points,
respectively. For Van Gogh, its target score increases by 0.62 points. SPEED
produces stronger erasure in all three tasks, with target scores lower than
TGPRS by 4.05 for Van Gogh, 0.79 for Picasso, and 3.01 for Monet.

TGPRS has substantially worse mean non-target FID than SPEED: higher by 86.37
for Van Gogh, 72.35 for Picasso, and 81.54 for Monet. It has higher MS-COCO CLIP
score in all three tasks, by 0.069, 0.400, and 0.162 points, but its MS-COCO FID
is worse by 1.07, 8.54, and 7.71 points, respectively.
