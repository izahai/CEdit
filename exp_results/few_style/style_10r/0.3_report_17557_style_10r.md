# Few-style erasure evaluation with 10-rank style subspace

The aggregate values are from the server's `summary.csv`; the matching
per-content results and run fingerprints are preserved in `detailed_metrics.csv`.

> The workflow completed on `root@61.32.91.194`, SSH port `17557`.
> SPEED uses threshold `0.1`, `aug_num=10`, and anchor `art`. Ours uses TGPRS
> with the original target prompts (`erase_style=false`), threshold `0.3`,
> `retain_scale=1.0`, `aug_num=0`, anchor `art`, and 10 artist-neutral anchors
> (configured and applied rank 10). The anchor list contains the empty prompt,
> `art`, `abstract art`, `painting`, `visual art`, `fine art`, `traditional art`,
> `contemporary art`, `classical painting`, and `modern painting`. Sampling uses
> seed 0, DPM-Solver, 20 denoising steps, and CFG 7.5. Each artist metric uses
> 30 images and each MS-COCO metric uses 100 images. The run contains 1,750 PNG
> files and six edited checkpoints.

Lower target CLIP score indicates stronger erasure. Lower non-target and MS-COCO
FID and higher MS-COCO CLIP score indicate better preservation. Bold values are
the better edited-model result within each task.

## Result summary

Rank-10 TGPRS reduces target CLIP score relative to the unedited model for all
three artists: by 2.64 for Van Gogh, 2.16 for Picasso, and 3.60 for Monet.
SPEED still produces lower target scores in every task, although the gap is
small for Picasso: TGPRS is higher by 0.80, 0.16, and 0.97 points,
respectively.

TGPRS has worse mean non-target FID than SPEED for all three tasks: higher by
18.92 for Van Gogh, 4.49 for Picasso, and 0.98 for Monet. Its MS-COCO CLIP score
is 0.102 lower than SPEED for Van Gogh but 0.118 and 0.297 higher for Picasso
and Monet. TGPRS improves MS-COCO FID over SPEED by 2.87 for Van Gogh and 2.24
for Monet, while it is 7.14 points worse for Picasso.
