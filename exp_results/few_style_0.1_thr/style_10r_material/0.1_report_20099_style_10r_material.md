# Few-style erasure evaluation with rank-10 material subspace

The aggregate values are from the server's `summary.csv`; the matching
per-content results and run fingerprints are preserved in `detailed_metrics.csv`.

> The workflow completed on `root@61.32.91.194`, SSH port `20099`.
> SPEED uses threshold `0.1`, `aug_num=10`, and anchor `art`. Ours uses TGPRS
> with the original target prompts (`erase_style=false`), threshold `0.1`,
> `retain_scale=1.0`, `aug_num=0`, anchor `art`, and ten material anchors:
> `brick`, `marble`, `cement`, `stone`, `granite`, `sand`, `plastic`, `ice`,
> `snow`, and `soil`. The configured and applied residual rank is 10. Sampling
> uses seed 0, DPM-Solver, 20 denoising steps, and CFG 7.5. Each artist metric
> uses 30 images and each MS-COCO metric uses 100 images. The run contains 1,750
> PNG files and six edited checkpoints.

Lower target CLIP score indicates stronger erasure. Lower non-target and MS-COCO
FID and higher MS-COCO CLIP score indicate better preservation. Bold values are
the better edited-model result within each task.

## Result summary

Rank-10 material-anchor TGPRS reduces target CLIP score relative to the
unedited model for all three artists: by 3.27 for Van Gogh, 2.04 for Picasso,
and 3.79 for Monet. SPEED produces the lower target score in every task, with
TGPRS trailing by 0.17, 0.28, and 0.78 points, respectively.

TGPRS has worse mean non-target FID than SPEED for every task: higher by 43.10
for Van Gogh, 23.17 for Picasso, and 34.44 for Monet. Its MS-COCO CLIP score is
0.068 lower than SPEED for Van Gogh, but 0.108 higher for Picasso and 0.237
higher for Monet. TGPRS has worse MS-COCO FID by 12.07 for Van Gogh, 18.01 for
Picasso, and 16.45 for Monet.
