# Few-style erasure evaluation with threshold 0.1 and rank-30 style subspace

The aggregate values are from the server's `summary.csv`; the matching
per-content results and run fingerprints are preserved in `detailed_metrics.csv`.

> The workflow completed on `root@61.32.91.194`, SSH port `20099`.
> SPEED uses threshold `0.1`, `aug_num=10`, and anchor `art`. Ours uses TGPRS
> with the original target prompts (`erase_style=false`), threshold `0.1`,
> `retain_scale=1.0`, `aug_num=0`, anchor `art`, and 100 artist-neutral anchors,
> with configured and applied residual rank 30. Sampling uses seed 0,
> DPM-Solver, 20 denoising steps, and CFG 7.5. Each artist metric uses 30 images
> and each MS-COCO metric uses 100 images. The run contains 1,750 PNG files and
> six edited checkpoints.

Lower target CLIP score indicates stronger erasure. Lower non-target and MS-COCO
FID and higher MS-COCO CLIP score indicate better preservation. Bold values are
the better edited-model result within each task.

## Result summary

Rank-30 TGPRS reduces target CLIP score relative to the unedited model for all
three artists: by 3.49 for Van Gogh, 1.81 for Picasso, and 4.00 for Monet. It
outperforms SPEED on Van Gogh erasure by 0.06 points, while trailing SPEED by
0.51 points for Picasso and 0.56 points for Monet.

TGPRS has worse mean non-target FID than SPEED for every task: higher by 43.21
for Van Gogh, 26.55 for Picasso, and 32.58 for Monet. Its MS-COCO CLIP score is
higher than SPEED by 0.014, 0.079, and 0.353 points, respectively. However,
TGPRS has worse MS-COCO FID by 12.06 for Van Gogh, 16.44 for Picasso, and 17.33
for Monet.
