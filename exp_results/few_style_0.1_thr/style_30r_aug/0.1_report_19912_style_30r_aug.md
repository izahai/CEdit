# Few-style erasure evaluation with threshold 0.1, rank-30 style subspace, and augmentation

The aggregate values are from the server's `summary.csv`; the matching
per-content results and run fingerprints are preserved in `detailed_metrics.csv`.

> The workflow completed on `root@61.32.91.194`, SSH port `19912`.
> SPEED uses threshold `0.1`, `aug_num=10`, `retain_scale=1.0`, and anchor `art`.
> Ours uses TGPRS with original target prompts (`erase_style=false`), threshold
> `0.1`, `retain_scale=1.0`, `aug_num=10`, anchor `art`, and 100 artist-neutral
> subspace anchors, with configured and applied rank 30. Sampling uses seed 0,
> DPM-Solver, 20 denoising steps, and CFG 7.5. Each artist metric uses 30 images
> and each MS-COCO metric uses 100 images. The completed run contains 1,750 PNG
> files and six edited checkpoints.

Lower target CLIP score indicates stronger erasure. Lower non-target and MS-COCO
FID and higher MS-COCO CLIP score indicate better preservation. Bold values are
the better edited-model result within each task.

## Result summary

TGPRS reduces target CLIP score relative to the unedited model for all three
artists: by 4.38 for Van Gogh, 1.94 for Picasso, and 4.66 for Monet. Compared
with SPEED, TGPRS produces target scores that are 0.94 lower for Van Gogh and
0.10 lower for Monet, while its Picasso target score is 0.38 higher.

Preservation is weaker overall. TGPRS non-target FID is worse than SPEED by 5.06
for Van Gogh, 7.02 for Picasso, and 1.99 for Monet. Its MS-COCO CLIP score is
0.186 lower for Van Gogh and 0.133 lower for Picasso, although it is 0.507 higher
for Monet. TGPRS also has worse MS-COCO FID in every task: by 1.64 for Van Gogh,
3.46 for Picasso, and 5.44 for Monet. Overall, adding `aug_num=10` at threshold
0.1/rank 30 yields stronger target erasure than SPEED for Van Gogh and Monet,
but does not translate into consistently better preservation.
