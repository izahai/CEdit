# Few-style erasure evaluation with threshold 0.4 and rank-30 style subspace

The aggregate values are from the server's `summary.csv`; the matching
per-content results and run fingerprints are preserved in `detailed_metrics.csv`.

> The workflow completed on `root@61.32.91.194`, SSH port `18776`.
> SPEED uses threshold `0.1`, `aug_num=10`, `retain_scale=1.0`, and anchor `art`.
> Ours uses TGPRS with original target prompts (`erase_style=false`), threshold
> `0.4`, `retain_scale=1.0`, `aug_num=0`, anchor `art`, and 100 artist-neutral
> subspace anchors, with configured and applied rank 30. Sampling uses seed 0,
> DPM-Solver, 20 denoising steps, and CFG 7.5. Each artist metric uses 30 images
> and each MS-COCO metric uses 100 images. The completed run contains 1,750 PNG
> files and six edited checkpoints.

Lower target CLIP score indicates stronger erasure. Lower non-target and MS-COCO
FID and higher MS-COCO CLIP score indicate better preservation. Bold values are
the better edited-model result within each task.

## Result summary

TGPRS reduces target CLIP score relative to the unedited model for all three
artists: by 3.94 for Van Gogh, 1.82 for Picasso, and 4.11 for Monet. Compared
with SPEED, TGPRS produces a 0.51 lower target score for Van Gogh, but target
scores are 0.49 higher for Picasso and 0.46 higher for Monet.

Preservation is mixed. TGPRS improves non-target FID over SPEED by 6.51 for
Monet, but is worse by 11.67 for Van Gogh and 5.14 for Picasso. Its MS-COCO CLIP
score is 0.052 higher for Picasso and 0.322 higher for Monet, but 0.206 lower for
Van Gogh. TGPRS improves MS-COCO FID by 3.89 for Van Gogh, while it is worse by
5.27 for Picasso and 2.36 for Monet. Overall, threshold 0.4/rank 30 strengthens
Van Gogh erasure and offers some task-specific preservation gains, but it does
not consistently outperform SPEED across the three style-erasure tasks.
