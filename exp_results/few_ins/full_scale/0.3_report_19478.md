values are from the matching `detailed_metrics.csv` run.

> The `Ours (TGPRS)` rows are from the full-scale run on SSH port `19478`, using
> threshold `0.3`, residual scale `0.6`, retain scale `1.0`, `params=V`, and
> `aug_num=0`. The configured TGPRS subspace contains 30 anchors, including the
> null prompt; the nominal and applied residual rank is 30. The `SPEED` rows are
> imported from `0.3_report_26908_ins_full.md` (SSH port `26908`, threshold `0.1`,
> and `aug_num=10`) and were not rerun in the `19478` workflow. Each concept
> metric uses 800 images, and each MS-COCO metric uses 1,000 images. Since the
> two methods come from separate runs, this is a reference comparison rather
> than a strictly same-run ablation.
