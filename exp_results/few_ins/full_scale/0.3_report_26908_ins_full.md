values are from the matching `detailed_metrics.csv` run.

> `26908`, using the same generated originals and latent sequence. SPEED uses
> threshold `0.1` with `aug_num=10`; Ours uses TGPRS threshold `0.3` with
> `aug_num=0` and 101 subspace anchors. Each concept metric uses 800 images, and
