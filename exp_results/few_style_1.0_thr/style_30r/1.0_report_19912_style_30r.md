# Few-style erasure evaluation with threshold 1.0 and rank-30 style subspace

The aggregate values are from the server's `summary.csv`; the matching
per-content results and run fingerprints are preserved in `detailed_metrics.csv`.

> The workflow completed on `root@61.32.91.194`, SSH port `19912`.
> SPEED uses threshold `0.1`, `aug_num=10`, `retain_scale=1.0`, and anchor `art`.
> Ours uses TGPRS with original target prompts (`erase_style=false`), threshold
> `1.0`, `retain_scale=1.0`, `aug_num=0`, anchor `art`, and 100 artist-neutral
> subspace anchors, with configured and applied rank 30. Sampling uses seed 0,
> DPM-Solver, 20 denoising steps, and CFG 7.5. Each artist metric uses 30 images
> and each MS-COCO metric uses 100 images. The completed run contains 1,750 PNG
> files and six edited checkpoints.

Lower target CLIP score indicates stronger erasure. Lower non-target and MS-COCO
FID and higher MS-COCO CLIP score indicate better preservation. Bold values are
the better edited-model result within each task.

## Result summary

TGPRS reduces target CLIP score relative to the unedited model for all three
artists: by 4.53 for Van Gogh, 2.00 for Picasso, and 4.59 for Monet. Compared
with SPEED, TGPRS produces target scores that are 1.09 lower for Van Gogh and
0.02 lower for Monet, while its Picasso target score is 0.32 higher.

Preservation remains artist-dependent. TGPRS improves non-target FID over SPEED
by 14.32 for Monet, but is worse by 16.12 for Van Gogh and 14.30 for Picasso.
Its MS-COCO CLIP score is 0.305 higher for Monet, but 0.071 lower for Van Gogh
and 0.072 lower for Picasso. In contrast, TGPRS improves MS-COCO FID in all
three tasks: by 6.49 for Van Gogh, 7.71 for Picasso, and 4.18 for Monet. Overall,
threshold 1.0/rank 30 provides strong Van Gogh and Monet erasure and consistently
better MS-COCO FID, but its non-target style preservation is substantially worse
for Van Gogh and Picasso.
