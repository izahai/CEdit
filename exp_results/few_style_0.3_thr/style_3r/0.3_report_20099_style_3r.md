# Few-style erasure evaluation with rank-3 style subspace

The aggregate values are from the server's `summary.csv`; the matching
per-content results and run fingerprints are preserved in `detailed_metrics.csv`.

> The workflow completed on `root@61.32.91.194`, SSH port `20099`.
> SPEED uses threshold `0.1`, `aug_num=10`, and anchor `art`. Ours uses TGPRS
> with the original target prompts (`erase_style=false`), threshold `0.3`,
> `retain_scale=1.0`, `aug_num=0`, anchor `art`, and 100 artist-neutral anchors,
> with configured and applied residual rank 3. Sampling uses seed 0, DPM-Solver,
> 20 denoising steps, and CFG 7.5. Each artist metric uses 30 images and each
> MS-COCO metric uses 100 images. The run contains 1,750 PNG files and six edited
> checkpoints.

Lower target CLIP score indicates stronger erasure. Lower non-target and MS-COCO
FID and higher MS-COCO CLIP score indicate better preservation. Bold values are
the better edited-model result within each task.

## Result summary

Rank-3 TGPRS reduces target CLIP score relative to the unedited model for all
three artists: by 3.73 for Van Gogh, 2.00 for Picasso, and 4.35 for Monet. It
outperforms SPEED on Van Gogh erasure by 0.30 points, while trailing SPEED by
0.32 points for Picasso and 0.21 points for Monet.

TGPRS has worse mean non-target FID than SPEED for every task: higher by 14.80
for Van Gogh, 5.22 for Picasso, and 1.15 for Monet. Its MS-COCO CLIP score is
lower than SPEED by 0.018 for Van Gogh and 0.104 for Picasso, but higher by 0.381
for Monet. TGPRS improves MS-COCO FID over SPEED by 1.79 for Van Gogh, while it
is worse by 11.46 for Picasso and 5.44 for Monet.
