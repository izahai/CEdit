# Few-style erasure evaluation with rank-5 style subspace

The aggregate values are from the server's `summary.csv`; the matching
per-content results and run fingerprints are preserved in `detailed_metrics.csv`.

> The workflow completed on `root@61.32.91.194`, SSH port `17557`.
> SPEED uses threshold `0.1`, `aug_num=10`, and anchor `art`. Ours uses TGPRS
> with the original target prompts (`erase_style=false`), threshold `0.3`,
> `retain_scale=1.0`, `aug_num=0`, anchor `art`, and 30 artist-neutral anchors,
> with configured and applied residual rank 5. The anchor set includes the empty
> prompt and neutral art, medium, brushwork, palette, and composition prompts.
> Sampling uses seed 0, DPM-Solver, 20 denoising steps, and CFG 7.5. Each artist
> metric uses 30 images and each MS-COCO metric uses 100 images. The run contains
> 1,750 PNG files and six edited checkpoints.

Lower target CLIP score indicates stronger erasure. Lower non-target and MS-COCO
FID and higher MS-COCO CLIP score indicate better preservation. Bold values are
the better edited-model result within each task.

## Result summary

Rank-5 TGPRS reduces target CLIP score relative to the unedited model for all
three artists: by 3.70 for Van Gogh, 2.26 for Picasso, and 3.72 for Monet. It
outperforms SPEED on Van Gogh erasure by 0.26 points, nearly matches SPEED for
Picasso with a 0.06-point higher target score, and trails SPEED by 0.84 points
for Monet.

TGPRS has worse mean non-target FID than SPEED for Van Gogh and Picasso, by
16.62 and 4.25 points, but improves Monet's non-target FID by 0.58. Its MS-COCO
CLIP score is lower than SPEED by 0.125 for Van Gogh and 0.048 for Picasso, but
higher by 0.287 for Monet. TGPRS improves MS-COCO FID over SPEED by 2.68 for Van
Gogh, while it is worse by 11.65 for Picasso and 4.91 for Monet.
